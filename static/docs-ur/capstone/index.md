# Capstone پروجیکٹ: ایند-ٹو-ایند ہیومنوائیڈ روبوٹکس سسٹم

## جائزہ

Capstone پروجیکٹ تمام چارو ماڈیولز کو جوڑ کر ایک مکمل ہیومنوائیڈ روبوٹکس سسٹم بناتا ہے جو قدرتی زبان کے کمانڈز سمجھنے، سمیولیشن میں کاموں کی منصوبہ بندی کرنے، اور جسمانی ہاڈ ویئر پر کام کرنے میں قابل ہے۔

## پروجیکٹ کے مقاصد

ایک ہیومنوائیڈ روبوٹ ڈیزائن اور نفذ کریں جو درج ذیل کر سکے:

1. **سمجھے**: `VLA` ماڈلز کا استعمال کرتے ہوئے قدرتی زبان کی کاموں کی تعلیمات پروسس کریں
2. **منصوبہ بنائے**: `Isaac Sim` ڈیجیٹل ٹوین میں `action` سیکوینسز بنائیں
3. **کام کریں**: جسمانی ہیومنوائیڈ ہاڈ ویئر پر `ROS 2` کنٹرول ڈیپلوئی کریں
4. **سکھیں**: مظاہروں اور فیڈ بیک سے بہتری کریں

## سسٹم آرکیٹیکچر

```
User Speech → Whisper → LLM Task Planner
                            ↓
                    VLA Action Predictor
                            ↓
                    Isaac Sim Validation
                            ↓
                    ROS 2 Hardware Control
```

## قابل فراہت

1. **ڈیزائن ڈاکیومنٹ**: سسٹم آرکیٹیکچر، جزیہ انتگریشن پلان
2. **سمیولیشن ڈیمو**: `Isaac Sim` میں ایند-ٹو-ایند کام کی عملداری
3. **ہاڈ ویئر ڈیمو**: جسمانی ہیومنوائیڈ جو `VLA`-کمانڈ شدہ کام کر رہا ہو
4. **آخری رپورٹ**: تکنیکی نفذ، چیلنجز، مستقبل کا کام

## تجویز شدہ کام

- قدرتی زبان کی تعلیمات کے ساتھ اٹھا کر رکھنا
- بصری خصوصیات کی بنیاد پر متعدد چیزوں کی چھانٹی
- اسمبلی کاموں کے لیے ٹول کا استعمال
- انسان-روبوٹ تعاون کے سیکنیرز

## جانچ کا معیار

- **تکنیکی گہرائی**: تمام 4 ماڈیولز کا انتگریشن
- **مضبوطی**: غلطیوں کی سنبھال اور حد کے معاملات
- **جدت**: نئے درخواستوں یا بہتری
- **دستاویزات**: ڈیزائن کے فیصلوں کی واضح وضاحت
