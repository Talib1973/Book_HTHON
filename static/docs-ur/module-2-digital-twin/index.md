# ماڈیول 2: ڈیجیٹل ٹوین (`Gazebo` اور `Unity`)

## جائزہ

ڈیجیٹل ٹوین ہاڈ ویئر پر ڈیپلوئی مینٹ سے پہلے فزیکس پر مبنی ماحولیات میں سمیولیشن کر کے محفوظ اور سستے روبوٹ کی ترقی ممکن بناتے ہیں۔ یہ ماڈیول `Gazebo Sim` (فزیکس پر مبنی سمیولیشن) اور `Unity ML-Agents` (RL ماحولیات) کور کرتا ہے۔

## آپ کیا سکھیں گے

### ہفتہ 6: `Gazebo` سمیولیشن
- `URDF` روبوٹ ماڈلز بنائیں
- سنسرز (`LIDAR`، کیمرے، `IMU`) سمیولیٹ کریں
- `Gazebo` کو `ROS 2` کے ساتھ جوڑیں

### ہفتہ 7: `Unity ML-Agents`
- RL ٹری�گ ماحولیات بنائیں
- ریوارڈ فنکشنز نفذ کریں
- مینپولیشن کاموں کے لیے پالیسیز ٹرین کریں

## سکھنے کے مقاصد

1. `URDF`/`SDF` فورمیٹز کا استعمال کرتے ہوئے روبوٹز ماڈل کریں
2. `Gazebo` کے ذریعے حقیقی فزیکس سمیولیٹ کریں
3. سمیولیٹ شدہ سنسرز کو `ROS 2` کے ساتھ جوڑیں
4. `Unity` میں RL ماحولیات بنائیں
5. ہاڈ ویئر ڈیپلوئی مینٹ سے پہلے روبوٹ پالیسیز ٹرین کریں
