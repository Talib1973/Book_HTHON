# ماڈیول 3: `NVIDIA Isaac Sim`

## جائزہ

`NVIDIA Isaac Sim` `GPU` سے تیز رفتار روبوٹکس سمیولیشن فراہت کرتا ہے جس میں فوٹو ریئلسٹک رینڈرنگ شامل ہے، جو AI ٹرینگ کے لیے بڑے پیمانے پر سنتھیٹک ڈیٹا جنریشن ممکن بناتا ہے۔

## آپ کیا سکھیں گے

### ہفتہ 8: `Isaac Sim` کی بنیادیات
- `Omniverse` کے ساتھ `Isaac Sim` سیٹ آپ کریں
- `USD` پر مبنی روبوٹ ماڈلز بنائیں
- سنسرز کے لیے `GPU` رے ٹریسنگ استعمال کریں

### ہفتہ 9: سنتھیٹک ڈیٹا جنریشن
- حصہ شدہ ٹرینگ ڈیٹا سیٹز بنائیں
- ڈومین رینڈمائزیشن تکنیکز
- سم-ٹو-ریئل ٹرانسفر

### ہفتہ 10: `Isaac Gym` انتگریشن
- `Isaac Gym` کے ساتھ RL پالیسیز ٹرین کریں
- ہزاروں ماحولیات کو متوازی کریں
- ٹرین شدہ ماڈلز کو `ROS 2` میں ڈیپلوئی کریں

## سکھنے کے مقاصد

1. فزیکس سمیولیشن کے لیے `GPU` ایکسیلریشن استعمال کریں
2. بڑے پیمانے پر سنتھیٹک ٹرینگ ڈیٹا بنائیں
3. RL پالیسیز کو مؤثر طریقے سے ٹرین کریں
4. سم میں ٹرین شدہ ماڈلز کو حقیقی روبوٹز میں منتقل کریں
